# Contributing

Contributions are welcome.

1. Fork the repository and create a focused branch.
2. Do not include real WeCom payloads, customer data, credentials, domains, IP addresses, databases, or private knowledge documents.
3. Run `uv sync --frozen --dev` and `./scripts/check.sh`.
4. Add tests for behavior changes.
5. Explain security and deployment implications in the pull request.

By contributing, you agree that your contribution is licensed under the MIT License.
